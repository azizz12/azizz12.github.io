GetClose, jeu de géographie en ligne

Une photo, une carte, cinq manches : le joueur doit deviner où la photo a été prise en cliquant sur une carte du monde, le plus près possible du vrai lieu. Plus il est proche, plus il marque de points.

  • Frontend en React et TypeScript (Vite), avec navigation entre les pages via React Router
  • Carte du monde interactive avec Leaflet, chronomètre de 60 secondes par manche
  • Calcul de la distance réelle entre deux points GPS (formule de Haversine), convertie en score sur 1 000 points
  • Appel à l'API OpenStreetMap (Nominatim) pour afficher la ville et le pays du point choisi
  • Back-end en FastAPI : comptes joueurs, authentification par JWT, mots de passe hachés, base PostgreSQL
  • Docker Compose pour lancer l'API et la base, tests automatisés avec pytest
  • TypeScript
  • React
  • Leaflet
  • Python
  • FastAPI
  • PostgreSQL
  • JWT
  • Docker
